# RPU Modern DLE Theme

A modern, responsive DataLife Engine theme with Tailwind CSS, vanilla JavaScript, and contemporary design patterns.

## Quick Start

### For Designers/Developers

1. **Install dependencies:**
   ```bash
   cd "DLE TPL"
   npm install
   ```

2. **Build CSS:**
   ```bash
   npm run build:css
   ```

3. **Development mode (auto-rebuild):**
   ```bash
   npm run dev
   ```

### For Site Administrators

Simply upload the theme to your DLE `templates/` directory and select it in the admin panel.

## Making Changes

### 1. Editing Templates

Edit `.tpl` files directly. Use Tailwind utility classes:

```html
<div class="flex items-center gap-4 p-4 bg-white rounded-lg">
  <h2 class="text-2xl font-semibold text-foreground">Title</h2>
</div>
```

After adding new classes, rebuild CSS:
```bash
npm run build:css
```

### 2. Editing Styles

**For utility classes:** Add to templates, then rebuild

**For custom CSS:** Edit `src/input.css`, then rebuild

**For legacy styles:** Edit `style/engine.css` or `style/components.css` directly

### 3. Editing JavaScript

Edit `js/theme.js` directly - no build step needed.

### 4. Changing Design Tokens

Edit CSS variables in `src/input.css`:

```css
:root {
  --text: #212121;
  --accent: #fc5621;  /* Change colors here */
  --background: #ffffff;
}
```

Then rebuild CSS.

## Design System

### Colors

| Token | Value | Usage |
|-------|-------|-------|
| `--text` | #212121 | Body text |
| `--accent` | #fc5621 | Primary accent (links, buttons) |
| `--background` | #ffffff | Page background |
| `--muted` | #ececf0 | Muted backgrounds |
| `--border` | rgba(33,33,33,0.1) | Borders |

### Typography

- **Font Family:** Inter
- **Weights:** 400 (regular), 600 (semibold), 700 (bold)
- **Fallback:** Inter Fallback, sans-serif

### Spacing

Uses Tailwind's spacing scale:
- `p-4` = 1rem (16px)
- `gap-3` = 0.75rem (12px)
- `mb-8` = 2rem (32px)

### Breakpoints

- `sm` - 640px
- `md` - 768px
- `lg` - 1024px
- `xl` - 1280px

## Troubleshooting

### Styles not updating?
1. Rebuild CSS: `npm run build:css`
2. Clear browser cache
3. Clear DLE cache (Admin Panel)

### JavaScript not working?
1. Check browser console (F12)
2. Ensure `theme.js` is loaded
3. Remove jQuery if present (causes conflicts)

### Icons not showing?
1. Ensure `fonts.css` is loaded
2. Use class `material-symbols-outlined`
3. Check internet connection (CDN)
